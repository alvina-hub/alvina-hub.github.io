# Alvina Prabhu Portfolio Website

Professional static portfolio website built for GitHub Pages.

## Upload instructions
Upload the files inside this folder directly to your GitHub Pages repository root. Do not upload the outer folder.

Required root files:
- index.html
- about.html
- projects.html
- resume.html
- contact.html
- style.css
- script.js
- alvina-headshot.png
- noshow-dashboard.png
- Alvina_Prabhu_Final_Resume.pdf
