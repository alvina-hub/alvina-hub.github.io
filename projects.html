Project 01

Healthcare Appointment No-Show & EHR Workflow Analysis

Analyzed a public healthcare appointment dataset to evaluate no-show trends by age group, SMS reminder status, and appointment weekday. Cleaned the dataset in Excel and built a Power BI dashboard with KPI cards, slicers, and visual reports.

Interactive Power BI dashboard built using a public healthcare appointment dataset for portfolio purposes.

ExcelPower BIHealthcare dataClinical workflowRequirements

Objective

Use appointment attendance data to identify patterns and propose an EHR-style workflow that supports reminder tracking, no-show follow-up, and rescheduling accountability.

Key findings

  • Overall no-show rate was approximately 20%.
  • No-show rate varied by age group, with younger adult patients showing higher no-show patterns.
  • SMS reminder status and appointment weekday showed differences that could support deeper workflow review.
  • Dashboard filters allow users to review patterns by gender, age group, and reminder status.

Clinical systems recommendations

  • Create a daily no-show follow-up workqueue for missed appointments.
  • Track reminder status as sent, received, failed, confirmed, or not reached.
  • Flag patients with repeated no-shows or long scheduling wait times.
  • Use dashboards to monitor trends by age group, weekday, reminder status, and clinic location.

Mock system requirements

REQ-001The system should display no-show rate by age group, SMS reminder status, and appointment weekday.
REQ-002The system should generate a daily list of patients who missed appointments.
REQ-003Staff should be able to document follow-up attempts after a missed appointment.
REQ-004The dashboard should allow filtering by gender, age group, and SMS reminder status.
REQ-005The system should flag patients with repeated missed appointments or long scheduling wait times.

Mock test cases

TC-001User filters dashboard by age group; dashboard updates to selected age group.
TC-002Appointment has no_show_flag = 1; appointment is included in no-show count.
TC-003User selects SMS reminder status; dashboard updates to selected reminder group.
TC-004Patient misses appointment; patient appears in follow-up workqueue.
TC-005Staff marks follow-up completed; patient is removed from open follow-up list.
